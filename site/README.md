# EasySell BD

অনলাইনে আয় প্ল্যাটফর্ম — ল্যান্ডিং, রেজিস্টার/লগইন (১০০ দেশের পতাকা + নাম্বার), ড্যাশবোর্ড, কাজ, উইথড্র, রেফার।

## ডেমো লগইন
- মোবাইল: `01700000000`
- পাসওয়ার্ড: `123456`

নতুন অ্যাকাউন্ট খুললে জয়েনিং বোনাস ৳৫০ পাবেন।

## চালাতে
ফোল্ডারে স্ট্যাটিক সার্ভার চালান, যেমন:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```
